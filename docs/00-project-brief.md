# Cheezish — Project Brief

## 1. Project Overview

Cheezish is a fictional demo burger restaurant website created for a professional portfolio.

The restaurant is based in Manchester, United Kingdom.

The website should demonstrate a premium, modern and technically advanced restaurant experience using cinematic 3D visuals while still remaining usable, responsive, accessible and performance-conscious.

---

## 2. Business

Business Name: Cheezish

Business Type: Burger Restaurant

Location: Manchester, United Kingdom

Project Type: Fictional Portfolio Demo

Cuisine Focus:
- Burgers
- Loaded Fries
- Drinks
- Desserts
- Deals

The project must not present fictional information as if it belongs to a real operating restaurant.

---

## 3. Target Users

The primary audience includes:

- Students
- Young adults
- Families
- Burger and fast-food lovers
- Users looking for food delivery in Manchester

The website should work well for both desktop and mobile users.

---

## 4. Primary Goal

The primary website action is:

**Order Food**

The user should always be able to clearly find an Order Now action.

---

## 5. Secondary Goals

Secondary user actions are:

- View Menu
- Book a Table
- Call Restaurant
- View Gallery
- Find Restaurant Information

---

## 6. Ordering Options

The demo website may display ordering options for:

- Uber Eats
- Deliveroo
- Just Eat

These must remain demo or placeholder links until real approved URLs are provided.

No real ordering integration is required in Version 1.

---

## 7. Website Pages

The website must contain:

1. Home
2. Menu
3. About
4. Gallery
5. Contact

Navbar:

CHEEZISH | Home | Menu | About | Gallery | Contact | ORDER NOW

The Cheezish logo should link back to the Home page.

---

## 8. Visual Direction

The visual style must be:

- Dark
- Cinematic
- Premium
- Futuristic
- Bold
- Food-focused

The design must not look like a generic restaurant template.

The website should feel immersive and high-end while keeping the food as the main visual focus.

---

## 9. 3D Direction

The Home page should use a full-screen cinematic 3D experience.

Desired effects include:

- Premium 3D burger
- Cinematic camera movement
- Smooth scroll-controlled animation
- Ingredient separation and reassembly
- Floating ingredient labels
- Subtle particles
- Atmospheric fog
- Premium lighting
- Cheese-inspired transitions
- Final cinematic Order Now scene

The uploaded 3D reference video is the primary motion and quality reference.

The reference should be used for principles and quality direction, not copied asset-for-asset.

---

The intended homepage sequence is:

1. Cheezish particle intro

4. Signature burger showcase
5. Cheese transition
6. Menu preview
7. Gallery preview
8. About preview
9. Final 3D Order CTA
10. Footer

- Gallery

- SEO basics
- Accessibility support

---

## 15. Out of Scope

Version 1 must NOT include:

- Real payment processing
- Shopping cart
- Real checkout
- Customer accounts
- Authentication
- Admin dashboard
- Production database
- Real order-management system
- Real delivery API integration
- CMS
- Production booking backend
- Fake customer reviews
- Fake awards
- Fake statistics
- Fake real-business claims

These features may be considered in a later phase.

---

## 16. Performance Constraints

The 3D experience must not make the website unusable.

Desktop may use the full visual experience.

Mobile and lower-capability devices should use reduced:

- Particle counts
- Texture sizes
- Shadow quality
- Post-processing
- Camera movement
- Expensive visual effects

The normal website content must remain accessible even if advanced 3D effects are reduced or unavailable.

---

## 17. Accessibility Constraints

The website must support:

- Keyboard navigation
- Visible focus states
- Semantic headings
- Accessible labels
- Appropriate color contrast
- Alternative text for meaningful images
- prefers-reduced-motion
- Readable HTML menu content

3D must enhance the experience rather than being the only way to access information.

---

## 18. Content Rules

Do not invent:

- Customer reviews
- Awards
- Real addresses
- Real phone numbers
- Real restaurant statistics
- Legal claims
- Delivery partnerships
- Business achievements

Demo data should be clearly treated as fictional project data.

---

## 19. Asset Rules

Do not use:

- Unlicensed images
- Unlicensed fonts
- Copied restaurant photography
- Copied website source code
- Random copyrighted 3D models
- Paid assets without approval

Record third-party asset source and license information.

---

## 20. Ownership

This is currently a portfolio/demo project.

Project files, repository, source assets and documentation should remain organized so the project can later be adapted for a real client.

---

## 21. Definition of Success

Cheezish should feel like a premium cinematic burger experience rather than a standard restaurant template.

The final website should:

- Make the food the main visual focus
- Provide a strong Order Now CTA
- Deliver an impressive 3D hero experience
- Remain fast enough to use
- Work properly on mobile and desktop
- Keep content accessible
- Avoid fake real-world claims
- Be maintainable and professionally structured
