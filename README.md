# 🍔 Cheezish

A cinematic, responsive restaurant website built with **Next.js, React, TypeScript and Framer Motion**.

Cheezish is a portfolio restaurant concept focused on bold food photography, premium dark UI, responsive layouts and polished motion interactions.

🌐 **Live Demo:** https://cheezish.vercel.app

---

## ✨ Features

- Cinematic restaurant landing page
- Responsive multi-page design
- Interactive restaurant menu
- Signature burger showcase
- Gallery and About pages
- Custom floating food doodle animations
- Smooth Framer Motion interactions
- Active navigation states
- Mobile-friendly responsive layout
- Optimized production deployment on Vercel

## 📌 Project Purpose

This project was created as a portfolio concept to demonstrate modern frontend development, responsive UI design, animation and production deployment.

> Cheezish is a fictional restaurant concept. No real orders, payments or reservations are processed.
